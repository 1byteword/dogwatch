🔌 Data Integrations

Send metrics to dogwatch using your existing tools. Compatible with Prometheus, Graphite, InfluxDB, OpenTSDB, StatsD, and DataDog agents.

📊 Metric Ingestion Endpoints
🔥

Prometheus

Remote Write Protocol
Active
Endpoint
# prometheus.yml remote_write: - url: "" # Optional: Add headers # headers: # Authorization: "Bearer <token>"
📈

Graphite

Plaintext & Pickle Protocol
Active
HTTP Endpoint
# Send metric via curl curl -X POST "" \ -d "servers.web01.cpu.usage 42.5 $(date +%s)" # Format: metric.path value timestamp
💧

InfluxDB

Line Protocol v1 & v2
Active
Write Endpoint
# Send metric via curl curl -X POST "?precision=s" \ -d "cpu,host=server01,region=us-west usage=42.5" # Telegraf config [[outputs.influxdb]] urls = [""] skip_database_creation = true
⏱️

OpenTSDB

HTTP JSON & Telnet
Active
Put Endpoint
# Send metric via curl curl -X POST "" \ -H "Content-Type: application/json" \ -d '[{ "metric": "sys.cpu", "timestamp": '$(date +%s)', "value": 42.5, "tags": {"host": "web01"} }]'
📡

StatsD

HTTP Bridge + DogStatsD Tags
Active
HTTP Endpoint
# Send via curl (HTTP bridge) curl -X POST "" \ -d "page.views:1|c|#page:home,user:member" # Format: metric:value|type|@sample_rate|#tags # Types: c=counter, g=gauge, ms=timer, s=set
🐕

DataDog Agent

V1 & V2 Series API
Active
Series Endpoint
# datadog.yaml - Point agent to dogwatch dd_url: api_key: any-key-works # Or set environment variables DD_DD_URL= DD_API_KEY=any-key-works
