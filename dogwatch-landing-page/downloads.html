Install Paths

Fast Path (Stable)

$ curl -sfL https://get.dogwatch.io/install | sudo sh -s -- --channel stable --token $DOGWATCH_TOKEN
$ dogwatch status

Pinned Binary

$ VERSION=v1.1.0
$ ARCH=linux-amd64
$ curl -LO https://dl.dogwatch.io/$VERSION/dogwatch-agent-$ARCH.tar.gz
$ tar -xzf dogwatch-agent-$ARCH.tar.gz
$ sudo install -m 0755 dogwatch /usr/local/bin/dogwatch

Container

$ docker pull ghcr.io/dogwatch/agent:v1.1.0
$ docker run --privileged --pid=host --network=host \
  -e DOGWATCH_TOKEN=$DOGWATCH_TOKEN \
  ghcr.io/dogwatch/agent:v1.1.0

Helm

$ helm repo add dogwatch https://charts.dogwatch.io
$ helm upgrade --install dogwatch-agent dogwatch/agent \
  --namespace observability --create-namespace \
  --set image.tag=v1.1.0 \
  --set token=$DOGWATCH_TOKEN

Verify Integrity

$ curl -LO https://dl.dogwatch.io/v1.1.0/SHA256SUMS
$ curl -LO https://dl.dogwatch.io/v1.1.0/SHA256SUMS.sig
$ gpg --keyserver keys.openpgp.org --recv-keys 0xD06F9B18A9E4E10A
$ gpg --verify SHA256SUMS.sig SHA256SUMS
$ shasum -a 256 -c SHA256SUMS --ignore-missing

Cosign signatures are also available for container images and chart artifacts.

Package Repository Setup

Debian / Ubuntu (APT)

$ curl -fsSL https://packages.dogwatch.io/gpg | gpg --dearmor | sudo tee /usr/share/keyrings/dogwatch.gpg > /dev/null
$ echo \"deb [signed-by=/usr/share/keyrings/dogwatch.gpg] https://packages.dogwatch.io/apt stable main\" | sudo tee /etc/apt/sources.list.d/dogwatch.list
$ sudo apt update && sudo apt install dogwatch-agent

RHEL / CentOS (YUM)

$ sudo tee /etc/yum.repos.d/dogwatch.repo <$ sudo yum install dogwatch-agent

macOS (Homebrew)

$ brew tap dogwatch/tap
$ brew install dogwatch-agent
$ dogwatch --version

Automation and Manifest APIs

CI/CD Friendly

Pin deterministic artifacts in pipeline jobs by reading signed release manifests.

$ curl -s https://dl.dogwatch.io/v1.1.0/manifest.json | jq '.artifacts[] | {target, sha256}'
$ curl -s https://dl.dogwatch.io/stable/latest.json | jq '.version'
$ curl -s https://dl.dogwatch.io/canary/latest.json | jq '.version'
1. Query channel metadata (stable, canary, nightly).
2. Resolve target artifact and expected SHA256 for architecture.
3. Download and verify signature before deployment step.
4. Record artifact digest in change-correlation timeline.

SBOM and Provenance

Every release ships with build provenance and SBOM exports for compliance and internal security review.

$ curl -LO https://dl.dogwatch.io/v1.1.0/dogwatch-agent-linux-amd64.sbom.spdx.json
$ curl -LO https://dl.dogwatch.io/v1.1.0/provenance.intoto.jsonl
$ cosign verify-attestation --type slsaprovenance \
  --key cosign.pub ghcr.io/dogwatch/agent:v1.1.0

Included Metadata

  • Build timestamp, Git commit, builder identity.
  • Compiler and dependency graph snapshot.
  • SPDX SBOM with package and license metadata.
  • Container image digest and signature bundle.

Downloads FAQ

Can we mirror artifacts internally?+

Yes. Mirror both artifact binaries and metadata files (manifest.json, checksums, signatures) to preserve deterministic verification in private networks.

How often should we move channels?+

Most teams pin to stable weekly and test canary in staging daily. Nightly should stay isolated to integration tests.

Are release artifacts reproducible?+

Provenance attestations and SBOM outputs are published per release to support reproducibility and audit workflows.
