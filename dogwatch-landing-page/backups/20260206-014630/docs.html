Installation

Deploying the dogwatch binary to your infrastructure.

Prerequisites

  • Linux Kernel 4.14+ (5.8+ recommended for full eBPF feature set).
  • Root privileges (required to attach eBPF probes).
  • Outbound access to api.dogwatch.io:443.

Standard Installation

The quickest way to get started is using our install script. This will detect your distribution, install the binary, and generate a default systemd service.

$ curl -sfL https://get.dogwatch.io/install | sudo sh -s -- --token YOUR_API_TOKEN

Docker / Kubernetes

Run as a DaemonSet to ensure every node is monitored. Privileged mode is required for eBPF access.

apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: dogwatch-agent
spec:
  template:
    spec:
      hostPID: true  # Required for process discovery
      containers:
      - name: agent
        image: dogwatch/agent:latest
        securityContext:
          privileged: true  # Required for eBPF
        env:
        - name: DOGWATCH_TOKEN
          valueFrom:
            secretKeyRef:
              name: dogwatch-secrets
              key: token

Verifying Installation

Check the agent status to ensure Golden Signals are streaming.

$ dogwatch status

[OK] Control Plane Connected
[OK] eBPF Probes Attached (24 probes active)
[OK] OTLP Receiver listening on 0.0.0.0:4317
