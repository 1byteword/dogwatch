Quickstart

Target time: 60 seconds

The agent auto-discovers entities, begins trace assembly, and streams Golden Signals immediately after startup.

$ curl -sfL https://get.dogwatch.io/install | sudo sh -s -- --token $DOGWATCH_TOKEN
$ sudo systemctl enable --now dogwatch-agent
$ dogwatch status

[OK] control_plane_connected=true
[OK] ebpf_probes_attached=24
[OK] spans_per_second=14203

Requirements

Category Minimum Recommended Notes
Linux kernel 4.14+ 5.8+ Needed for full eBPF and richer uprobes support.
Privileges root / CAP_BPF root Agent must attach kprobes and read process/network metadata.
Network egress 443 TCP 443 + NTP TLS to control plane plus stable time sync for incident correlation.
OTLP compatibility 4317 gRPC 4317 + 4318 Accepts OpenTelemetry protocol traffic from existing instrumentation.

Install Methods

Systemd Host Install

$ curl -LO https://dl.dogwatch.io/stable/linux/amd64/dogwatch-agent
$ sudo install -m 0755 dogwatch-agent /usr/local/bin/dogwatch
$ sudo dogwatch install --token $DOGWATCH_TOKEN
$ sudo systemctl restart dogwatch-agent

Kubernetes DaemonSet

apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: dogwatch-agent
spec:
  template:
    spec:
      hostPID: true
      containers:
      - name: agent
        image: ghcr.io/dogwatch/agent:v1.1.0
        securityContext:
          privileged: true
        env:
        - name: DOGWATCH_TOKEN
          valueFrom:
            secretKeyRef:
              name: dogwatch-secrets
              key: token

Agent Config

This baseline keeps high-value traces, enables cost intelligence, and activates core security detections.

agent:
  service_name: "prod-edge"
  env: "production"

capture:
  protocols: [http, https, mysql, postgres, redis]
  parse_wire_format: true
  enable_ssl_uprobes: true

sampling:
  mode: tail
  keep_errors: true
  latency_threshold_ms: 450
  baseline_rate: 0.05

control_plane:
  utility_scoring: true
  suggest_aggregation: true
  team_quota_series: 1200000

security:
  ruleset: default
  baseline_learning_window: 72h
  alert_on_shell_spawn: true
  alert_on_unusual_outbound: true

Data Pipeline

TCP/syscall events -> eBPF ring buffer -> protocol parser -> entity synthesis
                -> trace assembly + golden signals -> control plane shaping
                -> storage/query layer -> dashboards + BubbleUp + change correlation

The control plane sits before storage to aggregate low-utility labels, enforce quotas, and surface impact previews before rules are applied.

Ports and Protocols

Port Protocol Direction Purpose
4317 OTLP gRPC Inbound OpenTelemetry spans/metrics ingest from existing apps.
4318 OTLP HTTP Inbound Optional HTTP ingest endpoint.
443 HTTPS Outbound Control plane sync, release metadata, rules, and policy updates.
53 DNS Outbound Agent endpoint and package host lookup.

Security Signals

Runtime Detections

  • [rule] shell_in_container -> sys_execve
  • [rule] unusual_outbound -> tcp_connect
  • [rule] sensitive_file_access -> sys_open
  • [rule] privilege_escalation -> sys_setuid

Baseline Learning

Each image learns normal processes, outbound destinations, and file access patterns.

Alerts are elevated only when behavior deviates from baseline and incident context supports risk.

Troubleshooting

Symptom Likely Cause Command Remediation
No traces visible Probes failed to attach dogwatch doctor --probes Check kernel compatibility and root privileges.
High CPU on agent Overly broad protocol parsing dogwatch config get capture Limit capture scope and enable sampling thresholds.
Control plane disconnected Firewall / token issue dogwatch status --verbose Verify token validity and outbound 443 access.
Missing HTTPS metadata SSL uprobes unavailable dogwatch debug ssl Upgrade kernel/tooling and ensure OpenSSL symbols are readable.
