# V2 UI Blueprint

This folder contains the Phase 0 blueprint for the new frontend direction.

## Goals
- Build a cohesive, premium observability product in Solid + TypeScript.
- Beat incumbent workflows on triage speed and usability.
- Keep a strict, tokenized design system with no ad-hoc styling.

## Documents
- `01-ia-map.md`: product information architecture.
- `02-route-map.md`: V2 route and page model.
- `03-component-inventory.md`: shared UI primitives and domain components.
- `04-workflows.md`: core workflow specs.
- `05-acceptance-criteria.md`: measurable done criteria.
- `06-implementation-backlog.md`: execution order and file-level targets.

## Constraints
- No-glow baseline visual language.
- No inline styles or inline event handlers in new V2 code.
- Performance budget must be enforced from the first milestone.
